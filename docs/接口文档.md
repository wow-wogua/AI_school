# 接口文档 —— report-server REST API

> 适用版本：2026-08-22（含 AI 任务队列与运维扩容批次：Excel 导入导出 / AI 用量 / 审计日志 / 学生流转 / OpenAPI）。Base URL：本地开发 `http://localhost:8080`，容器化部署 `http://localhost`（web 容器 nginx 反代 `/api → server`）。交互式接口文档（Swagger UI）：容器 `http://localhost/swagger-ui.html`，本地 `http://localhost:8080/swagger-ui.html`。

## 认证与角色

**认证方式**：JWT Bearer。除 `POST /api/auth/login` 外，所有接口均需请求头 `Authorization: Bearer <token>`（OPTIONS 预检放行；无状态、无 session）。token 由登录接口返回，有效期 12 小时。

**角色与数据范围**（`DataScopeService`）：

| 角色 | 数据范围 |
|---|---|
| `ADMIN` 管理员 | 全校，不受数据范围限制 |
| `HEAD_TEACHER` 班主任 | 仅所带班级 |
| `TEACHER` 任课教师 | 仅任课班级（t_teach），所教科目外只读 |

下文"学生可见"= 该学生所在班级在当前用户可见班级列表内；"本班班主任"= ADMIN 或该班班主任（任课教师只读）。管理端 `/api/admin/**` 各组**全部仅 ADMIN**，组内不再逐条重复。

## 统一响应结构

- 除下文明示"二进制"的 5 类文件端点外，统一返回 `ApiResponse<T>`：`{code:int, message:string, data:T}`
  - 成功：`code=0`、`message="ok"`、`data` 为业务数据（无数据时 `data=null`）
  - 失败：`code` 为业务错误码（400/401/403/404/500/502），HTTP 状态码与之一致，`message` 为可直接展示的中文提示
- 参数校验失败：HTTP 400，`message` 形如 `"字段名: 中文消息"`
- **401 行为**：未带/无效/过期 token 返回 HTTP 401 + `{code:401,message:"未登录或登录已过期"}`；登录接口密码错误同样 401。前端收到 401 一律清除 token 并跳转 `/login`
- 403：无权限（如"只有管理员或该班班主任可执行此操作"、"无权访问该学生（数据权限隔离）"）
- 429：登录防爆破——同一用户名连续失败触发锁定（Redis 计数，自动过期），锁定期内登录返回 429「失败次数过多，请 N 分钟后再试」
- 二进制端点（`/api/report/file/*`、`/api/honor/file/*`、`/api/activity/{id}/cover`、`/api/admin/student/{id}/photo`、`/api/score/template`）不包 ApiResponse，直接返回文件字节流，**仍需带 Authorization 头**（iframe 无法带头，前端用 fetch 拉取 Blob）

## AuthController `/api/auth`

- `POST /api/auth/login` — 登录换 token（**公开**）
  - body：`username:String @NotBlank`、`password:String @NotBlank`
  - 返回：`{token, user{id,username,realName,role}}`（密码错 401；停用账号 403）
- `GET /api/auth/me` — 当前登录用户信息。返回：`{id,username,realName,role}`

## MetaController `/api/meta`（全部需登录）

- `GET /api/meta/terms` — 学期下拉（当前学期排前）。返回 `Term[]{id,name,startDate,endDate,isCurrent}`
- `GET /api/meta/grades` — 年级列表。返回 `Grade[]`
- `GET /api/meta/grids` — 九格下拉（按 sort）。返回 `Grid[]{id,code,name,icon,sort}`
- `GET /api/meta/indicators` — 评价用二级指标（过滤空名占位）。参数：`gridId?`。返回 `Indicator[]`
- `GET /api/meta/subjects` — 学科列表。返回 `Subject[]`
- `GET /api/meta/my-classes` — 我的班级下拉，**按数据范围过滤**。返回 `[{id,name,gradeId}]`

## StudentController `/api/student`

- `GET /api/student/list` — 学生选择（发起报告用），**按数据范围过滤，仅返回在读**（转出/毕业学生不参与日常业务；全量含历史届请用管理端 `/api/admin/student/list` 的 `status` 筛选）
  - 参数：`classId?`、`keyword?`（姓名模糊）、`page=1`、`size=20`（上限 100）
  - 返回：`{total, records[{id,studentNo,name,gender,classId,status}]}`

## ScoreController `/api/score`

- `POST /api/score/exam` — 建考试（含科目与满分）。**仅 ADMIN**
  - body：`termId:Long @NotNull`、`name:String @NotBlank`、`examDate:LocalDate @NotNull`、`subjects:[{subjectId:Long, fullScore:BigDecimal}] @NotEmpty`（科目不可重复）
  - 返回：`{examId}`
- `GET /api/score/exam/list` — 考试列表。需登录。返回 `[{id,termId,termName,name,examDate,classMaxTotal,gradeMaxTotal,subjectCount}]`
- `GET /api/score/subject-context` — 某班某考试可操作科目。参数：`examId`、`classId`（班级须可见）
  - 返回：`[{subjectId,name,fullScore,classMax,gradeMax,editable}]`（任课教师仅见所教科目，editable=false）
- `GET /api/score/list` — 某班某科成绩单。参数：`examId`、`subjectId`、`classId`（班级须可见）
  - 返回：`{fullScore, editable, rows[{studentId,studentNo,name,score,classRank,gradeRank}]}`（缺分 null）
- `GET /api/score/export` — 成绩单导出 xlsx（当前成绩单原样落表）。权限同查看。参数：`examId`、`subjectId`、`classId`。**二进制**（文件名如 `成绩_期末考试_语文_初一(2)班.xlsx`）
- `PUT /api/score/entry` — 批量录入。权限：**ADMIN 或该班该科任课教师**
  - body：`examId/subjectId/classId:Long @NotNull`、`rows:[{studentId:Long, score:BigDecimal}]`（score=null 清除；0≤score≤满分）
  - 返回：`{saved}`
- `POST /api/score/import` — Excel 导入。权限同 entry。multipart：`examId`、`subjectId`、`classId`、`file`
  - 返回：`{saved, skipped[{studentNo,name,reason}]}`（按班内学号匹配，留空不动）
- `GET /api/score/template` — 下载导入模板（该班名册预填 .xlsx，班级须可见）。**二进制**

## EvaluationController `/api/evaluation`（写权限 = 学生可见，任课教师可评所教班学生）

- `POST /api/evaluation` — 录过程性评价（即时写穿九格聚合表）
  - body：`studentId:Long @NotNull`、`indicatorId:Long @NotNull`、`title:String @NotBlank`、`score:BigDecimal @NotNull`、`remark:String?`、`evalTime:LocalDateTime @NotNull`（**必填**）
  - 返回：`{evaluationId, termId, weekNo}`
- `GET /api/evaluation/list` — 某生某学期评价列表。参数：`studentId`、`termId`（学生须可见）
  - 返回：`[{id,evalTime,gridName,indicatorName,title,score,remark,teacherName}]`

## ComprehensiveController `/api/comprehensive`

- `GET /api/comprehensive` — 查五维等级。参数：`studentId`、`termId`。权限：学生可见
  - 返回：`{studentId,termId,moral,ability,health,aesthetic,practice,finalLevel}`（未录全空串）
- `PUT /api/comprehensive` — 录入/修改（upsert）。权限：**ADMIN 或本班班主任**
  - body：`studentId/termId:Long @NotNull`、`moral/ability/health/aesthetic/practice:String?`（空或 A–D）
  - 返回：同 GET；`finalLevel` 服务端按"众数并列取高"裁定

## HonorController `/api/honor`

- `POST /api/honor/upload` — 上传证书 → AI 识别 → 落"待确认"。权限：**ADMIN 或本班班主任**
  - multipart：`studentId`、`file`（≤10MB，jpg/jpeg/png/pdf；图片走 AI 视觉识别，PDF/失败降级手动）
  - 返回：`{honorId, fileUrl, source:ai|manual, detail, parsed{name,level,issuer,date}}`
- `GET /api/honor/list` — 某生荣誉列表（含待确认，时间倒序）。参数：`studentId`（须可见）。返回 `Honor[]{name,level,issuer,honorDate,fileUrl,confirmStatus,...}`
- `PUT /api/honor/{id}` — 编辑待确认荣誉字段。权限同上传。body：`name/level/issuer/honorDate`（均可空）。仅"待确认"态可编辑
- `PUT /api/honor/{id}/confirm` — 确认生效（须先填奖项名）。权限同上传。body：`coin:BigDecimal?`（>0 时能量币入账）
  - 返回：`{termId}`（入账学期，未入账 null）
- `DELETE /api/honor/{id}` — 删除（仅待确认态，已确认的关联币账不可删）。权限同上传
- `GET /api/honor/file/{id}` — 证书原件预览（inline 图片/PDF）。权限：学生可见。**二进制**

## ActivityController `/api/activity`

- `GET /api/activity/list` — 活动列表（开始时间倒序）。需登录。返回 `Activity[]{id,title,type,startTime,place,intro,coverUrl,...}`
- `POST /api/activity` — 建活动。**仅 ADMIN**。body：`title:String @NotBlank`、`type/startTime/place/intro?`。返回 `{activityId}`
- `PUT /api/activity/{id}` — 改活动。**仅 ADMIN**。body 同上
- `DELETE /api/activity/{id}` — 删活动。**仅 ADMIN**（已有参与记录则 400）
- `POST /api/activity/{id}/cover` — 传封面。**仅 ADMIN**。multipart：`file`（jpg/jpeg/png ≤5MB，重复上传覆盖）。返回 `{coverUrl}`
- `GET /api/activity/{id}/cover` — 封面图。需登录。**二进制**（未上传 404）
- `GET /api/activity/{id}/signups` — 某活动参与记录，**按数据范围过滤**。返回 `[{signupId,studentId,studentName,classId,signupTime,checkinTime,award,performance}]`
- `POST /api/activity/{id}/signup` — 录参与（报名/签到/获奖/表现）。权限：**ADMIN 或本班班主任**
  - body：`studentId:Long @NotNull`、`checkin:Boolean?`（true 即签到）、`award/performance?`、`coin:BigDecimal?`（>0 须填 award，入账一次）
  - 返回：`{signupId, termId}`（入账学期，未入账 null）
- `PUT /api/activity/{id}/signup/{signupId}` — 改参与记录（只动签到/奖项/表现）。权限同上。body：`award/performance/checkin?`

## TimelineController `/api/timeline`

- `GET /api/timeline/{studentId}` — 成长事件时间轴（评价/活动/荣誉/成绩进步）。参数：`termId`（必填）。权限：学生可见
  - 返回：`{events[{type,time,title,detail}]}`

## AiController `/api/ai`（读=学生可见；生成/保存寄语=**ADMIN 或本班班主任**）

- `POST /api/ai/analysis` — 学业分析（规则引擎硬数字，不调大模型）。body：`studentId/termId:Long @NotNull`（无成绩 400）
  - 返回：`{advantage, toImprove, trend, alerts[]}`
- `POST /api/ai/comment-draft` — 班主任寄语草稿·**同步版**（AI 失败降级模板，存 t_comment.ai_draft）。body 同上
  - 返回：`{draft, source:llm|template, status}`。单发生成仍可用；页面已默认走下方任务队列
- `GET /api/ai/comment` — 寄语现状。参数：`studentId`、`termId`。返回 `{content, aiDraft, status}`（无记录 status="无"）
- `GET /api/ai/comment/export` — 寄语导出（班级×学期 → xlsx，含草稿与生效内容）。权限：**ADMIN 或该班班主任**。参数：`classId`、`termId`。**二进制**（文件名如 `寄语_初一(2)班_2025年秋季学期.xlsx`）
- `PUT /api/ai/comment` — 保存/确认寄语（confirm=true 才进报告）
  - body：`studentId/termId:Long @NotNull`、`content:String @NotNull`、`confirm:boolean`。返回同 GET
- `POST /api/ai/summary` — 成长总结草稿·**同步版**（不落库仅展示）。body 同 analysis
  - 返回：`{raw, blocks{本学期亮点,学习发展,综合素质发展,下一阶段建议}, source}`
- `POST /api/ai/tasks` — **任务队列·提交**（入队即返；切页/关浏览器后端照跑；同学生同类型未完成自动去重复用）
  - body：`type:String @NotNull`（`COMMENT`=寄语 / `SUMMARY`=总结）、`studentId/termId:Long @NotNull`。返回 `{taskId}`
- `GET /api/ai/tasks/{id}` — **任务队列·详情**（轮询取果）。权限：任务学生可见
  - 返回：`{taskId,type,studentId,termId,status(排队/生成中/成功/失败),source,error,createTime,startedTime,finishedTime, queuePosition?, result?}`——排队中附 `queuePosition`（前方第 N 位）；成功后 `result` 即同步接口的 data（COMMENT=`{draft,source,...}`，SUMMARY=`{raw,blocks,source}`）
- `GET /api/ai/tasks/mine` — **任务队列·我提交的近期任务**（全局任务面板数据源，含学生姓名）。参数：`limit=50`（上限 200）。按 `created_by` 过滤，**互相不可见**

**任务队列对接模式**：提交拿 taskId → 轮询 `mine`（前端 2s）驱动列表/进度 → 关心的任务转 `详情` 拿结果体。寄语结果另持久化于 `t_comment.ai_draft`（`GET /api/ai/comment` 可随时回显）；总结仅在任务 `result` 中。服务重启未完成任务自动重新入队。

## ReportController `/api/report`

- `POST /api/report/generate` — 单份生成（30s 内出 PDF，优先级最高）。权限：学生可见 + **ADMIN 或本班班主任**
  - body：`studentId/termId:Long @NotNull`。返回 `{taskId,termId,scope,targetId,status,total,done,failed}`
- `POST /api/report/generate-batch` — 班级批量。权限：**ADMIN 或该班班主任**。body：`classId/termId:Long @NotNull`。返回同上
- `POST /api/report/generate-grade` — 年级批量。**仅 ADMIN**。body：`gradeId/termId:Long @NotNull`。返回同上
- `POST /api/report/task/{id}/retry` — 失败重试。权限：任务可读。返回同 taskView
- `GET /api/report/task/{id}` — 任务进度。权限：任务可读（单生=学生可见；班级/年级=目标在可见范围内）
  - 返回：`{taskId,status,total,done,failed,scope,createTime}`
- `GET /api/report/task/list` — 近期任务列表（按可读性过滤）。参数：`limit=10`（上限 50）。返回 `taskView[]`
- `GET /api/report/list` — 某班某学期报告列表（每生取最新一份）。参数：`classId`、`termId`（班级须可见）
  - 返回：`[{reportId,studentId,status,fileUrl,genTime,error,taskId}]`
- `GET /api/report/data/{studentId}` — 契约 JSON（调试/契约校验，同渲染核心输入）。参数：`termId`。权限：学生可见
- `GET /api/report/file/{reportId}` — PDF 预览/下载。参数：`disposition=inline|download`。权限：报告学生可见。**二进制 PDF**

## AdminTermController `/api/admin`（学期，仅 ADMIN）

- `GET /api/admin/term/list` — 学期列表。返回 `Term[]`
- `POST /api/admin/term` — 建学期。body：`name:String @NotBlank`、`startDate/endDate:LocalDate @NotNull`、`isCurrent:Integer?`（设 1 则全局单活切换）。返回 `{termId}`
- `PUT /api/admin/term/{id}` — 改学期。body 同上（唯一当前学期不可被取消当前，400）
- `DELETE /api/admin/term/{id}` — 删学期（当前学期或已有考试的学期 400）

## AdminIndicatorController `/api/admin`（九格指标，仅 ADMIN）

- `GET /api/admin/grid/list` — 九格列表（本体只读）。返回 `[{id,code,name,icon,sort,indicatorCount}]`
- `GET /api/admin/indicator/list` — 指标列表（含空名占位）。参数：`gridId?`。返回 `Indicator[]`
- `POST /api/admin/indicator` — 建指标。body：`gridId:Long @NotNull`、`name:String @NotBlank`、`direction?`（默认"+"）、`defaultScore:BigDecimal?`、`subjectScope?`。返回 `{indicatorId}`
- `PUT /api/admin/indicator/{id}` — 改指标（被评价引用时禁止改名/移格，400）。body 同上
- `DELETE /api/admin/indicator/{id}` — 删指标（被评价引用 400）

## AdminTemplateController `/api/admin`（报告模板，仅 ADMIN）

- `GET /api/admin/template/list` — 模板列表。返回 `ReportTemplate[]{id,schoolName,sections(JSON串),status(启用/草稿),...}`
- `POST /api/admin/template` — 建草稿模板。body：`schoolName:String @NotBlank`、`sections:String @NotBlank`（合法 JSON 对象字符串）。返回 `{templateId}`
- `PUT /api/admin/template/{id}` — 改草稿模板（启用模板锁定只读，400）
- `DELETE /api/admin/template/{id}` — 删草稿模板（启用模板 400）
- `PUT /api/admin/template/{id}/status` — 状态切换：**一律 400**（启用即改契约基线，需 DBA 介入，前端无此入口）

## AdminUserController `/api/admin`（教师账号与任课，仅 ADMIN）

- `GET /api/admin/user/list` — 账号分页列表（不回传密码）。参数：`role?`、`keyword?`（用户名/姓名）、`page=1`、`size=20`（上限 100）。返回 `{total, records[{id,username,realName,role,phone,status}]}`
- `POST /api/admin/user` — 建账号。body：`username/password/realName/role:String @NotBlank`、`phone?`；role ∈ `ADMIN/HEAD_TEACHER/TEACHER`；用户名唯一。返回 `{userId}`
- `PUT /api/admin/user/{id}` — 改账号。body：`realName/role/phone` 全可选；不能改自己的角色
- `PUT /api/admin/user/{id}/password` — 重置密码。body：`password:String @NotBlank`
- `PUT /api/admin/user/{id}/status` — 停用/启用。body：`status:Integer @NotNull`（0/1；不能停用自己）
- `DELETE /api/admin/user/{id}` — 删账号（不能删自己；有任课关系或班主任身份 400）
- `GET /api/admin/teach/list` — 任课关系列表。参数：`teacherId?`。返回 `[{id,teacherId,teacherName,classId,className,subjectId,subjectName}]`
- `POST /api/admin/teach` — 建任课关系。body：`teacherId/classId/subjectId:Long @NotNull`（三者组合唯一）。返回 `{teachId}`
- `DELETE /api/admin/teach/{id}` — 删任课关系

## AdminOrgController `/api/admin`（年级/班级/学生档案，仅 ADMIN）

- `GET /api/admin/grade` — 年级列表。返回 `Grade[]`
- `POST /api/admin/grade` — 建年级。body：`name:String @NotBlank`、`schoolYear?`。返回 `{gradeId}`
- `PUT /api/admin/grade/{id}` — 改年级。body 同上
- `DELETE /api/admin/grade/{id}` — 删年级（下有班级 400）
- `GET /api/admin/class/list` — 班级列表（附年级名/班主任名）。返回 `[{id,gradeId,gradeName,name,headTeacherId,headTeacherName}]`
- `POST /api/admin/class` — 建班级。body：`gradeId:Long @NotNull`、`name:String @NotBlank`、`headTeacherId:Long?`（绑定班主任）。返回 `{classId}`
- `PUT /api/admin/class/{id}` — 改班级（可换班主任）。body 同上
- `DELETE /api/admin/class/{id}` — 删班级（下有学生 400）
- `PUT /api/admin/class/{id}/move-students` — **整班调班（升年级/分班）**：全班在读学生移入目标班，历史数据按「学生+学期」关联不受影响。body：`targetClassId:Long @NotNull`（≠自身、须存在）。返回 `{moved}`
- `PUT /api/admin/class/{id}/mark-status` — **整班标记状态（毕业/转出）**：换届时整届学生一键退场，档案与报告保留可查。body：`status:String`（仅支持 `毕业` / `转出`）。返回 `{updated}`
- `GET /api/admin/student/list` — 学生档案分页（含家长信息）。参数：`classId?`、`keyword?`（姓名/学号）、`status?`（在读/转出/毕业，**不传=全部**，历史届归档查询用）、`page=1`、`size=20`（上限 100）。返回 `{total, records[Student完整字段]}`
- `POST /api/admin/student` — 建学生档案。body：`studentNo:String @NotBlank`（唯一）、`name:String @NotBlank`、`gender?`、`classId:Long @NotNull`、`enrollDate?`、`status?`（默认"在读"）、`photoUrl?`、`guardianName?`、`guardianPhone?`。返回 `{studentId}`
- `PUT /api/admin/student/{id}` — 改学生档案。body 同上
- `DELETE /api/admin/student/{id}` — 删学生（已有任何成长数据——评价/成绩/活动/综评/寄语/荣誉——一律 400 拒删）
- `POST /api/admin/student/import` — **新生 Excel 批量导入**：逐行校验，合法行入库、问题行返回明细（部分成功语义）。multipart：`file`（.xlsx，首行表头；列：学号、姓名、性别[男/女]、班级[须已存在]、监护人姓名、监护人电话；导入学生一律"在读"）。返回 `{inserted, failed, errors[{row,reason}]}`
- `GET /api/admin/student/import-template` — 新生导入模板（仅表头 .xlsx）。**二进制**
- `POST /api/admin/student/{id}/photo` — 传学生照片。multipart：`file`（jpg/jpeg/png ≤5MB，覆盖旧图）。返回 `{photoUrl}`
- `GET /api/admin/student/{id}/photo` — 学生照片（档案缩略图）。**二进制**

## 大模型（AI）接入与模型切换指南

### 调用大模型的位置（共 3 处）

| 功能 | 入口 | 模型要求 |
|---|---|---|
| 班主任寄语草稿 | 寄语页「AI 生成草稿」/「本班全部生成」→ `POST /api/ai/tasks(type=COMMENT)` | 纯文本模型 |
| 成长总结四块 | 总结页「AI 分析该学生」→ `POST /api/ai/tasks(type=SUMMARY)` | 纯文本模型 |
| 荣誉证书图片识别 | 证书上传 `POST /api/honor/upload` | **必须多模态（vision）模型** |

协议为 **OpenAI 兼容 Chat Completions**（DeepSeek / 通义千问 / 智谱 / Kimi / OpenAI 均可）。AI 只组织语言，**全部数字与事实由规则引擎计算后注入提示词**，模型无法编造；寄语须教师确认后才进报告。

### 配置在哪、怎么换模型

**Docker 部署（推荐）**：编辑 `docker-compose.override.yml`（首次从 `docker-compose.override.yml.example` 复制），改完 `docker compose up -d report-server`：

```yaml
services:
  report-server:
    environment:
      AISCHOOL_AI_BASE_URL: https://api.deepseek.com   # 供应商 OpenAI 兼容地址
      AISCHOOL_AI_API_KEY: sk-你的key                  # 密钥只放本文件（已 gitignore，勿入库）
      AISCHOOL_AI_MODEL: deepseek-v4-flash             # ★ 换模型只改这一行
      # AISCHOOL_AI_CONCURRENCY: 16                    # 可选：任务并发（默认 16）
```

**本地开发**：改 `report-server/src/main/resources/application.yml` 的 `aischool.ai` 段（base-url / api-key / model / concurrency / timeout-seconds）。

| 环境变量 | 配置项 | 默认 | 说明 |
|---|---|---|---|
| `AISCHOOL_AI_BASE_URL` | aischool.ai.base-url | 空 | 留空 = 不启用 AI |
| `AISCHOOL_AI_API_KEY` | aischool.ai.api-key | 空 | 留空 = 不启用 AI |
| `AISCHOOL_AI_MODEL` | aischool.ai.model | 空 | 留空 = 不启用 AI；**三项须同时配置** |
| `AISCHOOL_AI_CONCURRENCY` | aischool.ai.concurrency | 16 | 任务队列 worker 数 = 对大模型的最大同时在途请求数 |
| — | aischool.ai.timeout-seconds | 120 | 单次 LLM 调用读超时，超时该条降级模板 |

**要同时用证书识别**：`AISCHOOL_AI_MODEL` 须配多模态模型（如 `deepseek-v4-flash-vision-exp` / `qwen-vl` / `glm-4v`）。

### 未配置 / 调用失败时的降级

- 三项配置留空 → 寄语/总结自动降级为**确定性规则模板**（硬数字仍准确），任务正常完成（source=template），前端有提示；证书转手动录入
- 单次调用失败/超时 → 同样降级模板，任务不报错；只有规则引擎本身异常（如无成绩）任务才置"失败"

### 供应商限额参考（DeepSeek 官方，2026-08 查证）

| 模型 | 并发上限/账号 | 超限行为 |
|---|---|---|
| deepseek-v4-flash | 2500 | HTTP 429（不封号） |
| deepseek-v4-pro | 500 | HTTP 429（不封号） |

默认并发 16 = flash 上限的 0.6%，多教师共用同一队列与 worker 池（并发不随教师数放大）；换限额更紧的供应商时按其限额调小 `AISCHOOL_AI_CONCURRENCY`。
